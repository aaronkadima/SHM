    Editor ou IDE?

    Qual a diferença entre um editor de código e uma IDE, e por que usar o VS Code na trilha?

    Um editor edita texto com recursos de código. Uma IDE junta editor, depurador, terminal e ferramentas de uma linguagem. O VS Code é um editor que vira IDE com extensões, para HTML, JS, Python e MATLAB no mesmo lugar.

    Use o VS Code como base para todos os cursos. MATLAB IDE e Jupyter continuam úteis para exploração; o código final vai para o repositório.

    Instalar o VS Code

    Como instalar o VS Code no Windows, macOS e Linux?

    Baixe em code.visualstudio.com ou use o gerenciador de pacotes do sistema. No Windows, marque "Adicionar ao PATH" e "Abrir com Code" no instalador.

    No macOS, abra a paleta de comandos e rode "Shell Command: Install 'code' command in PATH" para usar code . no terminal.

    A interface

    Quais são as áreas principais da janela do VS Code?

    Barra de atividades à esquerda (Explorador, Pesquisa, Controle de Código, Executar e Depurar, Extensões), área de edição no centro, painel inferior (Terminal, Problemas, Saída) e barra de status embaixo.

    Se esquecer um atalho, a paleta de comandos encontra a ação pelo nome e mostra o atalho ao lado.

    Atalhos de edição

    Quais atalhos economizam mais tempo ao editar código?

    Múltiplos cursores, mover linhas, renomear símbolos e formatar o documento.

    F2 é o mais seguro para renomear: troca tensao por tensaoMPa só onde é a mesma variável, sem pegar textos parecidos.

    Pasta como projeto

    Por que abrir a pasta inteira, e não arquivos soltos?

    Abrindo a pasta, o VS Code entende o projeto: Git, terminal na raiz, busca em todos os arquivos, configurações próprias em .vscode/.

    Versionar a pasta .vscode/ faz quem clonar o repositório ter o mesmo ambiente que você.

    settings.json

    Como fazer o editor formatar sempre ao salvar e marcar o limite de 100 colunas?

    Abra "Preferences: Open User Settings (JSON)" para regras gerais ou edite .vscode/settings.json para o projeto.

    Configurações de projeto vencem as de usuário. Assim o Python usa 4 espaços e o JavaScript 2, sem você lembrar.

    Instalar e configurar o Git

    O que fazer logo depois de instalar o Git?

    Instale e configure nome, e-mail e o nome padrão da branch principal. Esses dados aparecem em cada commit.

    Use o mesmo e-mail cadastrado no GitHub para os commits aparecerem ligados ao seu perfil.

    Conectar ao GitHub

    Como autenticar o computador no GitHub sem digitar senha a cada push?

    Duas formas comuns: GitHub CLI (login pelo navegador) ou chave SSH. O GitHub não aceita mais a senha da conta para operações Git.

    Com SSH, clone usando o endereço git@github.com:usuario/repo.git. Com o gh, o endereço HTTPS já funciona.

    Conta GitHub no VS Code

    Para que entrar com a conta GitHub dentro do VS Code?

    O ícone de contas (canto inferior esquerdo) permite entrar com o GitHub. Isso libera clonar repositórios privados, abrir Pull Requests e sincronizar configurações entre computadores.

    Com Settings Sync, o notebook do laboratório e o seu computador pessoal ficam com as mesmas extensões e atalhos.

    Controle de Código

    Como fazer add, commit e push sem sair do editor?

    O painel de Controle de Código (Ctrl+Shift+G) lista arquivos modificados. O "+" prepara (add), a caixa de mensagem faz o commit e "Sincronizar" faz pull e push.

    Revise o diff antes de cada commit. É ali que você vê um peso .pt ou uma foto que escapou do .gitignore.

    Clonar e Pull Requests

    Como clonar um repositório e revisar PRs dentro do VS Code?

    "Git: Clone" na paleta baixa o repositório. A extensão GitHub Pull Requests lista, comenta e revisa PRs no editor.

    Revisar o PR de um orientando no editor permite rodar o código da branch dele antes de aprovar.

    Extensões essenciais

    Quais extensões instalar para os cursos da trilha?

    Instale pela aba Extensões (Ctrl+Shift+X) ou pelo terminal com o identificador de cada uma.

    Instale só o que vai usar. Extensões demais deixam o editor lento e às vezes brigam entre si na formatação.

    Extensões recomendadas

    Como garantir que quem clonar o projeto instale as mesmas extensões?

    Liste-as em .vscode/extensions.json. Ao abrir a pasta, o VS Code oferece instalar as que faltam.

    É a forma mais simples de padronizar o ambiente de um grupo de pesquisa sem escrever manual de instalação.

    Live mode com Live Server

    Como ver a página HTML atualizar sozinha a cada vez que salvo?

    A extensão Live Server cria um servidor local e recarrega o navegador ao salvar. Clique em "Go Live" na barra de status ou clique com o botão direito no HTML e escolha "Open with Live Server".

    Abrir o HTML com duplo clique (file://) quebra fetch e módulos. Com o Live Server a página roda como num site de verdade.

    Live Server ou Vite?

    Quando usar Live Server e quando usar o servidor do Vite?

    Live Server serve arquivos como estão: ideal para HTML, CSS e JS puros (cursos 3 a 5). Projetos React/TypeScript precisam do Vite, que compila e atualiza só o módulo alterado (HMR) sem perder o estado da tela.

    Não rode os dois na mesma pasta. Escolha um por projeto para não confundir qual porta está atualizada.

    Testar no celular

    Como abrir a página em desenvolvimento no celular ou no headset?

    Exponha o servidor na rede local e acesse pelo IP do computador, com os dois aparelhos no mesmo Wi-Fi. Câmera e WebXR exigem HTTPS fora do localhost.

    É assim que você testa a ficha de campo no celular e a cena VR no headset sem publicar nada.

    Formatar e checar

    Prettier e ESLint fazem a mesma coisa?

    Não. Prettier cuida da aparência (espaços, aspas, quebras). ESLint aponta erros e más práticas (variável não usada, comparação com ==). Use os dois.

    Com formatOnSave, o Prettier arruma ao salvar e o ESLint sublinha problemas enquanto você digita.

    Depurar no editor

    Como pausar o código numa linha e inspecionar variáveis?

    Clique à esquerda do número da linha para criar um breakpoint e inicie a depuração (F5). O painel mostra variáveis, pilha de chamadas e permite avançar linha a linha.

    Depurar é mais rápido que espalhar console.log para achar por que a máscara saiu vazia.

    Node.js e npm

    O que é preciso instalar para os cursos de JavaScript e React?

    Node.js na versão LTS, que traz o npm. Um gerenciador de versões (nvm ou fnm) permite trocar de versão por projeto.

    Prefira a versão LTS: bibliotecas como Three.js e ONNX Runtime Web testam primeiro nela.

    Python no VS Code

    Como fazer o VS Code usar o ambiente virtual do projeto?

    Crie o .venv na pasta e selecione-o como interpretador. O terminal integrado passa a ativá-lo sozinho.

    Se aparecer "módulo não encontrado" mesmo depois do pip install, quase sempre o interpretador selecionado não é o do .venv.

    MATLAB no VS Code

    Dá para editar e rodar arquivos .m no VS Code?

    Sim, com a extensão oficial da MathWorks. Ela precisa de um MATLAB instalado e licenciado no computador e oferece realce, análise de código e execução.

    Use o VS Code para versionar e revisar os .m junto com o resto do projeto. Para explorar dados com gráficos interativos, o MATLAB continua mais prático.

    Terminal e WSL

    No Windows, como ter as ferramentas de Linux que muitos tutoriais usam?

    O WSL roda um Linux dentro do Windows. Com a extensão WSL, o VS Code abre pastas do Linux como se fossem locais.

    COLMAP, Open3D e muitas bibliotecas de visão computacional têm instalação mais simples no Linux.

    Remote SSH: servidor com GPU

    Como editar e rodar código no servidor de GPU do laboratório como se fosse local?

    A extensão Remote SSH conecta o VS Code a outra máquina. Os arquivos e o terminal ficam no servidor; só a interface roda no seu computador.

    Rode treinos longos dentro de tmux no servidor: se a conexão cair, o treino da U-Net continua.

    Site ou aplicação web?

    Qual a diferença entre um site e uma aplicação web?

    Um site apresenta conteúdo para ler e navegar. Uma aplicação web deixa o usuário criar, editar e guardar dados, como um programa que roda no navegador. As duas usam HTML, CSS e JavaScript.

    O Project Card começa como aplicação estática e, mais tarde, passa a ler e gravar os projetos numa API do backend da plataforma.

    O que é marcação

    Qual a diferença entre uma linguagem de marcação e uma linguagem de programação?

    Uma linguagem de marcação descreve o que cada parte do conteúdo é (título, parágrafo, lista). Ela não tem variáveis, laços nem decisões. A lógica fica com o JavaScript.

    O IFC em formato texto (STEP) e o XML de muitos sistemas de aquisição também são formatos de descrição de dados, não programas.

    Anatomia de um elemento

    Quais são as partes de um elemento HTML?

    Tag de abertura, conteúdo e tag de fechamento. A tag de abertura pode ter atributos no formato nome="valor".

    O nome da tag diz o que o conteúdo é. Os atributos acrescentam informação: identificação, classe de estilo, destino de um link.

    Aninhamento

    Qual regra de aninhamento o HTML abaixo quebra?

    Elementos devem fechar na ordem inversa em que abriram, como parênteses. O primeiro exemplo fecha o strong depois do p.

    O navegador tenta corrigir erros de aninhamento, mas cada navegador corrige do seu jeito. Use a indentação do editor para ver a hierarquia.

    Elementos vazios

    Por que img, input e br não têm tag de fechamento?

    São elementos vazios: não têm conteúdo, só atributos. Escreva apenas a tag de abertura.

    A barra no final (<img />) é aceita, mas desnecessária em HTML5. Escolha um estilo e mantenha no projeto.

    Atributos booleanos

    Como marcar um campo como obrigatório ou um botão como desativado?

    Atributos booleanos valem pela presença. Escrever o atributo já liga a opção; para desligar, remova o atributo.

    No JavaScript, use a propriedade: botao.disabled = false remove o efeito do atributo.

    Comentários e entidades

    Como escrever um comentário no HTML e mostrar o caractere < na página?

    Comentários ficam entre <!-- e --> e não aparecem na página. Caracteres reservados são escritos como entidades.

    Comentários são visíveis para quem abre o código-fonte. Nunca deixe senhas ou dados de obra sensíveis neles.

    O que é o DOM

    O que o navegador faz com o arquivo HTML antes de mostrar a página?

    Ele lê o texto e monta o DOM (Document Object Model): uma árvore de objetos, um para cada elemento, texto e atributo. O JavaScript lê e altera essa árvore, não o arquivo.

    Mudar o DOM muda a página na hora. O arquivo index.html no disco continua igual.

    Nós e relações

    Como se chamam as relações entre elementos na árvore do DOM?

    Pai, filhos, irmãos, ancestrais e descendentes. O JavaScript navega por essas relações.

    closest é muito útil em eventos: a partir do botão clicado, você acha o card inteiro ao qual ele pertence.

    Selecionar elementos

    Quais métodos buscam elementos no DOM?

    getElementById busca pelo id. querySelector devolve o primeiro que casa com um seletor CSS. querySelectorAll devolve todos.

    Se o método devolve null, ou o seletor está errado ou o script rodou antes do HTML existir. Use type="module" ou coloque o script no fim do body.

    Criar elementos

    Como acrescentar um novo card de projeto à lista pelo JavaScript?

    Crie o elemento, preencha classe e conteúdo e insira na árvore com append.

    Se o texto vier de um formulário, use textContent para o nome e a descrição. innerHTML com texto digitado permite injetar código na página.

    Alterar e remover

    Como mudar o status de um card, trocar sua aparência e removê-lo?

    Altere texto com textContent, classes com classList, atributos com setAttribute e remova com remove().

    Prefira trocar classes a mudar style direto. A aparência continua no CSS e o JavaScript só diz o estado.

    DOM no DevTools

    Como ver e testar o DOM ao vivo no navegador?

    F12 abre as ferramentas de desenvolvedor. A aba Elements mostra o DOM atual; o Console executa JavaScript na página.

    Teste o seletor no Console antes de colocar no código. Se $(".project-card").length der 0, o problema é o seletor.

    Os três papéis

    Que parte do site cada tecnologia resolve?

    HTML dá estrutura e significado, CSS dá aparência e layout, JavaScript dá comportamento. Manter cada um no seu arquivo facilita manter o projeto.

    Teste: desligue o CSS e o JS. A página ainda deve fazer sentido como documento. Se não fizer, a estrutura HTML está fraca.

    Site estático

    O que torna um site "estático"?

    O servidor entrega os arquivos exatamente como estão no disco. Não há banco de dados nem código rodando no servidor; tudo que muda acontece no navegador.

    Um site estático é suficiente para o protótipo do Project Card, para catálogos e para material de curso como esta trilha.

    Anatomia de uma URL

    Quais são as partes de uma URL?

    Protocolo, domínio, porta (opcional), caminho, parâmetros de consulta e fragmento.

    O fragmento (#oae-017) não vai ao servidor: serve para pular a uma parte da página ou guardar qual item está aberto.

    Caminhos relativos

    A imagem não aparece. Como escrever o caminho certo para ela?

    Caminhos relativos partem do arquivo atual. ./ é a pasta atual, ../ sobe uma pasta, e / no início parte da raiz do site.

    Caminhos começando com / funcionam no Live Server, mas quebram no GitHub Pages quando o site fica dentro de /repositorio/. Prefira relativos.

    Cliente e servidor

    O que acontece entre digitar a URL e ver a página?

    O navegador (cliente) pede cada arquivo ao servidor por HTTP. O servidor responde com o arquivo e um código de status.

    Página sem estilo? Abra a aba Network e procure o style.css: se aparecer 404, é caminho errado.

    Estrutura de pastas no VS Code

    Como organizar as pastas de um site estático?

    Separe páginas, estilos, scripts e arquivos de mídia. Abra a pasta raiz no VS Code e rode com o Live Server.

    Um arquivo por classe, com o mesmo nome da classe, faz qualquer pessoa achar o código só pelo Explorador.

    Snippets e Emmet

    Como gerar o esqueleto da página e blocos repetidos sem digitar tudo?

    O VS Code traz o Emmet: abreviações que viram HTML ao apertar Tab. Snippets próprios guardam trechos que você usa sempre.

    Crie seus snippets em "Snippets: Configure Snippets". Um snippet do card de projeto padroniza a estrutura de todos os cards.

    Semântica do app

    Como estruturar a página de um app de projetos com tags semânticas?

    Barra lateral de navegação, área principal com cabeçalho de página e a lista de cards. Cada região usa a tag que diz o seu papel.

    Com essa estrutura, leitores de tela anunciam "navegação" e "principal", e o CSS Grid posiciona as duas regiões com poucas linhas.

    Estrutura do card

    Quais partes um card de projeto precisa ter?

    Cabeçalho (ícone com iniciais e nome), descrição e uma lista de propriedades no formato rótulo/valor.

    dl, dt e dd são a tag certa para pares rótulo/valor, como uma ficha técnica.

    Seletores para o card

    Que seletor CSS pega só as propriedades do card, só o status ativo e o card sob o mouse?

    Combine classe, descendente, classe dupla e pseudo-classe.

    Use id para o JavaScript achar o elemento e classe para o CSS estilizar. Assim mudar o visual nunca quebra o script.

    Grid de cards

    Como fazer a lista de cards ocupar quantas colunas couberem na tela?

    repeat(auto-fill, minmax(...)) cria colunas com largura mínima e divide o espaço restante.

    Sem nenhuma media query na lista, ela já vai de 1 coluna no celular a 4 num monitor largo.

    id e classe

    Quando usar id e quando usar class?

    Um id é único na página e identifica um elemento. Uma class pode se repetir e agrupa elementos parecidos. Um elemento pode ter várias classes.

    Ids repetidos não dão erro visível, mas getElementById passa a devolver só o primeiro e o resto da lógica falha em silêncio.

    Objetos de projeto

    Como guardar os dados de um projeto antes de desenhar o card?

    Um objeto JavaScript reúne os dados do projeto. O card é só a visualização desse objeto.

    Separar dado e tela permite salvar os projetos em JSON, exportar para outra plataforma e redesenhar os cards sem perder nada.

    A classe Project

    Como garantir que todo projeto nasça com os mesmos campos e saiba criar o próprio card?

    Uma classe define o molde. O constructor recebe os dados e um método cria o elemento do card.

    Guardar o elemento em this.ui liga o objeto ao seu card: alterar o status pode atualizar a tela no mesmo método.

    O gerenciador de projetos

    Quem guarda a lista de projetos e coloca os cards na página?

    Uma segunda classe gerencia a coleção: cria projetos, impede nomes repetidos e insere os cards no container.

    A regra de negócio (nome único) fica num lugar só. A interface só chama novoProjeto e mostra o erro, se houver.

    Eventos

    Como abrir o formulário ao clicar em "Novo projeto" e criar o card ao enviar?

    addEventListener liga uma função a um evento. No envio do formulário, preventDefault impede a página de recarregar e FormData lê os campos.

    Os nomes dos campos (name="nome") viram as chaves do objeto dados. Mantenha-os iguais aos campos da classe Project.

    Delegação de eventos

    Como reagir a cliques em cards criados depois que a página carregou?

    Escute o evento no container e descubra qual card foi clicado com closest. Um único listener atende cards atuais e futuros.

    Sem delegação, cada card novo precisaria do seu próprio listener, e é fácil esquecer de criar ou de remover.

    Convenções de nomes

    PascalCase, camelCase, kebab-case: onde usar cada um?

    Cada linguagem tem sua convenção. Segui-la deixa claro, só pelo nome, o que cada coisa é.

    Em React, componentes precisam começar com maiúscula (PascalCase): <ProjectCard /> é componente, <projectCard /> é tratado como tag HTML.

    Node e npm

    Para que serve o Node.js num site que roda no navegador?

    O Node roda JavaScript fora do navegador. No desenvolvimento web ele executa as ferramentas: servidor local, empacotador, formatador, testes. O site final continua rodando no navegador.

    O site estático pode começar sem Node, só com Live Server. O Node entra quando você precisa de bibliotecas como Three.js ou de TypeScript.

    Pacotes e package.json

    O que fica registrado no package.json e o que não vai para o Git?

    O package.json lista dependências e scripts. O package-lock.json fixa as versões exatas. A pasta node_modules é recriada com npm install e fica fora do repositório.

    Versione o package.json e o package-lock.json. Quem clonar roda npm install e tem as mesmas versões que você.

    Importar pacotes

    Como usar um pacote instalado pelo npm no código do site?

    Importe pelo nome do pacote. O Vite resolve o nome para o arquivo dentro de node_modules e entrega ao navegador.

    O npm run build gera de novo um site estático em dist/, que pode ir para o GitHub Pages como qualquer outro.

    Estrutura mínima

    Quais partes compõem a estrutura básica de um HTML?

    DOCTYPE, html, head com metadados e body com conteúdo visível.

    A declaração do tipo de documento, os metadados e o corpo delimitam as áreas principais de uma página web.

    Referências a arquivos

    Como o HTML carrega CSS e JavaScript externos?

    Use link rel=stylesheet e script src; defer evita execução antes da leitura do HTML.

    Caminhos relativos devem apontar para as pastas reais do projeto, inclusive após publicação no GitHub Pages.

    Fluxo de desenvolvimento

    Como testar e publicar um site estático?

    Edite no VS Code, execute um servidor local, confira no navegador e publique em hospedagem estática.

    Publicar exige testar o site localmente e verificar os arquivos acessíveis na URL final.

    Grid versus Flexbox

    Quando escolher Grid em vez de Flexbox?

    Grid é ideal para linhas e colunas; Flexbox organiza itens numa direção e alinha conteúdo interno.

    No SHM Studio, Grid organiza as colunas de project cards, enquanto Flexbox organiza botões e informações internas.

    Classes JavaScript

    class em JavaScript é igual à classe CSS?

    Não. CSS class agrupa elementos para estilos; class em JavaScript define um modelo de objetos.

    A classe CSS identifica elementos para estilizar; uma classe JavaScript fornece estrutura e comportamento a objetos.

    Node: dois sentidos

    Qual é a diferença entre um DOM node e Node.js?

    DOM node é uma unidade da árvore do documento; Node.js é um runtime de JavaScript.

    Um nó do DOM representa parte da página; Node.js é o ambiente de execução usado pelas ferramentas de desenvolvimento.

    Links e botões

    Como decidir entre <a> e <button> num card?

    Use <a href> para navegar e <button> para uma ação, como marcar favorito.

    Use links em cards para acessar outras páginas e botões para executar ações na interface.

    Quando o DOM está pronto?

    Como garantir que o script encontre os elementos antes de acessá-los?

    Carregue o script externo com defer ou espere o evento DOMContentLoaded antes de consultar os elementos da página.

    Este cuidado evita seletores vazios quando o código executa antes da criação do contêiner de project cards.

    O que é controle de versão

    Que problema um sistema de controle de versão resolve?

    Ele guarda o histórico de cada mudança nos arquivos: quem mudou, quando e por quê. Você pode comparar versões, voltar atrás e trabalhar em paralelo sem sobrescrever o trabalho dos outros.

    Na pesquisa, o histórico mostra exatamente qual versão do código gerou cada figura e tabela de um artigo.

    Git ou GitHub?

    Git e GitHub são a mesma coisa?

    Não. Git é o programa de controle de versão, que roda no seu computador e funciona sem internet. GitHub é um serviço on-line que hospeda repositórios Git e acrescenta colaboração: Pull Requests, issues, Actions e Pages.

    Você pode trocar de serviço de hospedagem sem perder o histórico, porque ele está no Git, não no site.

    Repositório

    Como começar a versionar um projeto novo ou baixar um existente do GitHub?

    git init cria um repositório na pasta atual. git clone copia um repositório remoto com todo o histórico.

    Cada plataforma (AstraStruct, SHM Vision Lab) é um repositório. Bibliotecas de cálculo compartilhadas podem virar um terceiro.

    O ciclo básico

    Quais três comandos você usa dezenas de vezes por dia?

    status mostra o que mudou, add escolhe o que entra no próximo registro e commit grava esse registro com uma mensagem.

    Commits pequenos e frequentes facilitam achar quando um resultado de cálculo mudou.

    .gitignore

    O que nunca deve entrar no repositório de um projeto de visão computacional?

    Dependências instaladas, datasets de imagens, pesos treinados grandes e segredos. Liste-os no .gitignore.

    Guarde no repositório o script que baixa o dataset, não o dataset. Chaves de API vão no .env, nunca no código.

    Mensagens e versões

    Como marcar que o código atual é a versão v0.29 da plataforma?

    Use mensagens com prefixo do tipo de mudança e crie uma tag para cada versão publicada.

    Num artigo, cite a tag. Assim o revisor reproduz exatamente o código que gerou os resultados.

    Branches

    Como testar um novo motor de segmentação sem quebrar a versão estável?

    Uma branch é uma linha de trabalho paralela. A main fica estável enquanto você experimenta.

    Uma branch por experimento: motor-unet, motor-yolo-seg, ajuste-limiar.

    GitHub: push e pull

    Como enviar seu trabalho e trazer o dos colaboradores?

    push envia commits ao remoto. pull traz e integra os commits remotos.

    Faça pull antes de começar o dia, principalmente se um orientando também mexe no código.

    Merge e conflitos

    O que fazer quando o Git avisa CONFLICT ao juntar branches?

    O Git marca no arquivo as duas versões. Você escolhe o texto final, apaga os marcadores e faz um commit.

    No GitHub, prefira abrir um Pull Request: ele mostra a diferença e guarda a discussão da mudança.

    Arquivos grandes

    Precisa versionar um peso de 90 MB. O que usar?

    O GitHub recusa arquivos acima de 100 MB e sofre bem antes disso. O Git LFS guarda o arquivo fora do histórico e deixa só um ponteiro.

    Para pesos e datasets públicos, um repositório de dados (Zenodo, Hugging Face) com DOI ajuda a citação nos artigos.

    Desfazer mudanças

    Errei um arquivo, adicionei algo errado ou escrevi a mensagem errada. Como desfazer?

    Cada situação tem um comando. revert é o seguro para commits que já foram para o GitHub, porque cria um commit novo em vez de apagar histórico.

    Evite git reset --hard e push --force em branches compartilhadas: apagam trabalho dos colegas.

    stash

    Estou no meio de uma mudança e preciso corrigir algo urgente na main. O que fazer?

    git stash guarda as mudanças não commitadas numa pilha e limpa a pasta. Depois você as recupera.

    Para trabalhos longos, prefira um commit numa branch. O stash é para interrupções curtas.

    GitHub Actions

    Como rodar os testes automaticamente a cada push?

    Um arquivo YAML em .github/workflows/ descreve o que o GitHub executa a cada push ou Pull Request.

    Com os testes das funções de calc/ rodando no CI, uma mudança que altere o momento máximo é barrada antes do merge.

    O que é HTML

    O que significa HTML e qual é o seu papel numa página?

    HyperText Markup Language: a linguagem de marcação que descreve a estrutura e o significado do conteúdo. "Hipertexto" porque os documentos se ligam por links.

    O HTML é mantido pelo WHATWG como um padrão vivo, atualizado continuamente. Por isso a referência é a documentação atual (MDN), não um livro de anos atrás.

    Esqueleto

    Qual é a estrutura mínima de uma página HTML?

    Declaração do tipo, idioma, codificação, viewport para celular, título e corpo.

    lang="pt-BR" e utf-8 evitam problemas com acentos e com µ, ε e °C.

    Tags semânticas

    Como dividir a tela de uma plataforma de inspeção em regiões com significado?

    Use tags que dizem o papel de cada parte. Elas ajudam leitores de tela, buscadores e a sua própria leitura do código.

    Funciona com teclado e leitor de tela sem nenhuma linha de código, o que nem sempre acontece com acordeões feitos à mão.

    dialog

    Como pedir confirmação antes de apagar uma anomalia registrada?

    O elemento dialog cria uma janela modal nativa, com foco preso dentro dela e fechamento com Esc.

    Ações destrutivas em campo precisam de confirmação: um toque errado com luva não pode apagar um registro.

    SVG no HTML

    Como desenhar um esquema simples da ponte que escala sem perder nitidez?

    SVG é desenho vetorial em texto. Cada forma é um elemento que pode ter id, classe e evento de clique.

    Um croqui em SVG com elementos clicáveis é um gêmeo digital mínimo, útil antes de ter o modelo IFC.

    Em React você escreve as mesmas tags em JSX. A semântica continua valendo.

    Texto e títulos

    Como estruturar o texto de um laudo na página?

    Títulos de h1 a h6 formam a hierarquia. Use só um h1 e não pule níveis.

    Escolha o título pelo nível no documento, não pelo tamanho da fonte. Tamanho é com CSS.

    Imagens e links

    Como inserir uma foto de anomalia de forma acessível?

    Toda imagem informativa precisa de alt. Use figure e figcaption para a legenda.

    width e height reservam o espaço e evitam que a página pule enquanto as fotos carregam.

    Tabelas

    Como montar o quadro de anomalias por elemento?

    Tabelas são para dados tabulares. Use thead, tbody e th com scope.

    Nunca use tabela para posicionar a tela. Layout é trabalho do CSS Grid.

    Formulários

    Como fazer o cadastro de uma anomalia em campo?

    Cada campo tem um label ligado pelo for/id. O name identifica o valor no envio.

    O label clicável aumenta a área de toque, essencial com luva no tablet em campo.

    Campos numéricos

    Como restringir a entrada de uma abertura de fissura em mm?

    type="number" com min, max e step abre teclado numérico e valida no navegador.

    capture="environment" abre direto a câmera traseira no celular.

    Canvas

    Onde desenhar a imagem com as máscaras de segmentação?

    canvas é uma área de pixels controlada por JavaScript. É a base do curso de JS para visão computacional.

    Dois canvas sobrepostos: um com a foto e outro com a máscara semitransparente, que pode ser ligada e desligada.

    Scripts e módulos

    Como ligar o JavaScript à página?

    type="module" permite import/export e já espera o HTML carregar.

    No Vite, o index.html já vem com essa linha apontando para main.jsx ou main.tsx.

    Atributos data-

    Como guardar o id do elemento estrutural num botão para o JavaScript ler depois?

    Atributos data-* guardam informação própria no HTML. O JS lê em el.dataset.

    Guardar o GlobalId do IFC no botão liga a lista de elementos ao modelo 3D (curso 11).

    O que é CSS

    O que significa CSS e o que quer dizer "cascata"?

    Cascading Style Sheets: folhas de estilo que definem a aparência do HTML. "Cascata" é a regra que decide qual estilo vence quando várias regras atingem o mesmo elemento: origem, especificidade e ordem.

    A maioria dos "CSS que não funciona" é uma regra mais específica vencendo. O DevTools mostra as regras riscadas e quem venceu.

    Seletores

    Como aplicar estilo a um elemento, a uma classe e a um id?

    Seletor de tag, de classe (.) e de id (#). Prefira classes: são reutilizáveis e têm especificidade baixa.

    Evite estilizar por id: ele vence quase tudo e dificulta ajustes futuros.

    Box model

    Por que a caixa ficou mais larga que o width definido?

    Por padrão, padding e border somam ao width. box-sizing: border-box faz o width incluir tudo.

    Coloque o reset de box-sizing na primeira linha de todo projeto.

    Unidades

    px, rem, % ou vh: qual usar para cada coisa?

    rem para texto e espaçamento (respeita o zoom do usuário), % e fr para larguras relativas, px para bordas finas.

    O visualizador 3D costuma ocupar a altura restante da tela. Veja Grid no próximo módulo.

    Flexbox

    Como alinhar os botões da barra de ferramentas do visualizador?

    Flexbox organiza itens em uma linha ou coluna. gap espaça sem margens.

    Use flex para uma dimensão (barras, listas). Para a tela inteira, use Grid.

    Grid

    Como montar o layout visualizador 3D + painel lateral de dados?

    Grid divide em linhas e colunas ao mesmo tempo. fr divide o espaço livre.

    Sem min-width: 0, o canvas do Three.js pode empurrar o painel para fora da tela.

    Responsivo

    Como empilhar o painel abaixo do visualizador no celular?

    Media queries aplicam regras a partir de uma largura. Escreva para o celular primeiro e expanda.

    Inspeção de campo acontece no celular e no tablet. Teste nessas larguras desde o começo.

    Sobreposição

    Como colocar rótulos de detecção sobre a foto?

    O pai recebe position: relative. Os filhos com position: absolute se posicionam dentro dele.

    Use porcentagem da imagem, não px, para o rótulo acompanhar quando a foto mudar de tamanho.

    Variáveis CSS

    Como trocar a cor de destaque da plataforma inteira em um só lugar?

    Custom properties guardam valores reutilizáveis, os tokens do design.

    O JS pode ler e alterar tokens: style.setProperty("--destaque", cor).

    Modo escuro

    Como respeitar o tema escuro do sistema do usuário?

    Redefina só os tokens dentro de prefers-color-scheme: dark. Os componentes não mudam.

    Ajuste também o fundo da cena 3D: modelo cinza-claro em fundo escuro dá melhor leitura.

    Cores de severidade

    Como mostrar o estado de um elemento sem depender só da cor?

    Combine cor, texto e forma. Cerca de 1 em 12 homens tem alguma deficiência na percepção de cores.

    No gêmeo 3D, junte a cor da malha a um ícone no painel e a um rótulo com a nota do elemento.

    clamp()

    Como fazer o título crescer com a tela sem ficar gigante no monitor nem minúsculo no celular?

    clamp(mínimo, ideal, máximo) escolhe o valor ideal dentro de limites.

    Substitui várias media queries de tamanho de fonte por uma linha.

    Container queries

    Como fazer o cartão do sensor mudar de layout conforme o espaço que ele recebe, e não a tela?

    Declare o pai como container e use @container nas regras do filho.

    O mesmo cartão funciona no painel lateral estreito e numa página de detalhe larga, sem código duplicado.

    Transições com cuidado

    Como animar o destaque de um elemento em alerta sem incomodar quem é sensível a movimento?

    Use transition para mudanças suaves e desative animações quando o sistema pedir redução de movimento.

    Evite piscar alertas. Uma mudança de cor com ícone é suficiente e não causa desconforto.

    O que é JavaScript

    O que é JavaScript e onde ele roda?

    A linguagem de programação da web. Roda em todos os navegadores e, com Node.js, também em servidores e ferramentas. Não tem relação com Java além do nome.

    É a única linguagem que roda nativamente no navegador do inspetor, por isso o gêmeo digital e a segmentação no campo passam por ela.

    const e let

    Quando usar const e quando usar let?

    const cria uma referência que não pode ser reatribuída. let pode mudar. Use const por padrão e evite var.

    Constantes do projeto (E, fck, vão) ficam em const. Estados que evoluem no tempo ficam em let ou, melhor, no estado do componente React.

    Tipos primitivos

    Quantos tipos numéricos o JavaScript tem para cálculo de engenharia?

    Só um: number, ponto flutuante de 64 bits (IEEE 754). Os outros primitivos usuais são string, boolean, null e undefined.

    Não existe int nem double separados. Inteiros são exatos até 2^53, suficiente para timestamps em ms.

    Armadilha do ponto flutuante

    Por que 0.1 + 0.2 === 0.3 retorna false?

    0,1 e 0,2 não têm representação binária exata. Compare grandezas físicas com tolerância, nunca com igualdade estrita.

    Ao checar se a flecha atingiu L/500, use >= e uma tolerância. toFixed é só para exibir, não para calcular.

    Objetos

    Como representar uma longarina com vão, seção e material?

    Um objeto agrupa propriedades nomeadas. Pode conter outros objetos.

    Cada elemento do gêmeo (laje, longarina, pilar, aparelho de apoio) vira um objeto com id ligado à geometria 3D.

    Condicionais

    Como transformar uma nota de condição em um rótulo de estado?

    Use if / else if ou um objeto de consulta. Use sempre ===, que não converte tipos.

    Confira as faixas e critérios na NBR 9452 antes de fixar os limites no código.

    Arrays

    Como guardar a série de leituras de um extensômetro?

    Um array é uma lista ordenada, indexada a partir de 0.

    Em produção, cada item costuma ser um objeto: { t, valor, sensorId }, para não perder o instante da medida.

    map

    Como converter todas as microdeformações em tensão (MPa) de uma vez?

    map aplica uma função a cada item e devolve um novo array do mesmo tamanho.

    Lei de Hooke (σ = E·ε) aplicada à série inteira, sem laço manual. O array original fica intacto.

    filter

    Como achar só as leituras que passaram do limite de alerta?

    filter mantém os itens para os quais a função retorna true.

    some responde "existe algum?" e para no primeiro achado. Bom para acender o alarme de um elemento.

    reduce

    Como calcular média e máximo de uma série?

    reduce percorre o array acumulando um único resultado.

    Para séries muito longas (milhões de pontos), prefira um laço for: o espalhamento ... em Math.max pode estourar a pilha.

    Laços

    Como percorrer todos os elementos estruturais de uma OAE?

    for...of percorre os valores. O for clássico dá acesso ao índice e é o mais rápido.

    Use for quando precisar de break ou desempenho; use map/filter quando quiser clareza.

    Funções

    Escreva o momento máximo de uma viga biapoiada com carga distribuída.

    Duas formas equivalentes: declaração e arrow function. ** é potência.

    Funções puras (mesma entrada, mesma saída) são fáceis de testar contra resultados do seu software de cálculo.

    Desestruturação

    Como tirar vao e h do objeto viga em uma linha?

    A desestruturação extrai campos de objetos e arrays para variáveis.

    Muito usado em props de componentes React: function Painel({ sensor, limite }).

    Template literals

    Como montar o texto "Vão 25 m · h/L = 0.064" com valores calculados?

    Strings com crase aceitam expressões dentro de ${} e quebras de linha.

    toLocaleString("pt-BR") resolve vírgula decimal e separador de milhar nos relatórios.

    Classes

    Como modelar um sensor que guarda o histórico e avisa quando passa do limite?

    Uma classe junta dados e comportamento. Cada new cria uma instância.

    Uma classe base Sensor e subclasses (Extensometro, Acelerometro) com extends.

    Módulos

    Como separar os cálculos estruturais em um arquivo próprio no projeto Vite?

    Cada arquivo é um módulo. Exporte o que é público e importe onde precisar.

    Uma pasta calc/ só com funções puras, sem tela, facilita testes e reuso entre plataformas.

    JSON

    O gateway de campo mandou texto. Como virar objeto JavaScript?

    JSON é o formato de troca de dados. parse lê, stringify escreve.

    Guarde o tempo como número em ms (UTC). Converta para fuso local só na hora de exibir.

    async / await

    Como buscar as últimas leituras de um sensor na API sem travar a tela?

    Rede é assíncrona. await espera a Promise sem bloquear a interface. Trate erros com try/catch.

    Para vários sensores em paralelo: await Promise.all(ids.map(ultimas)).

    Tempo real

    Polling com setInterval ou WebSocket: qual usar no monitoramento?

    setInterval pergunta ao servidor de tempos em tempos. WebSocket mantém um canal aberto e o servidor envia quando há dado novo.

    Polling basta para inspeção periódica. Para acelerômetros e prova de carga ao vivo, use WebSocket.

    DOM e eventos

    Como mostrar a flecha atual na página e reagir a um clique?

    O DOM é a árvore da página. Você seleciona elementos e escuta eventos.

    Com React você raramente mexe no DOM direto: muda o estado e o React redesenha. Mas é isto que acontece por baixo.

    Cena 3D com Three.js

    Quais são as peças mínimas para desenhar uma longarina em 3D?

    Cena, câmera, renderizador e uma malha (geometria + material), redesenhados num laço.

    Use as unidades da obra (1 unidade = 1 m) para que posições de sensores e fissuras batam com o projeto.

    Dado vira cor

    Como pintar a longarina de verde a vermelho conforme a tensão medida?

    Normalize o valor entre 0 e 1 e converta para um matiz HSL (120° verde, 0° vermelho).

    Este é o coração do gêmeo digital: a geometria reage ao dado do sensor. Sempre mostre a legenda da escala.

    Um passo para TypeScript

    Como impedir que alguém misture leitura em mm com leitura em µε?

    TypeScript adiciona tipos ao JavaScript e acusa erros antes de rodar. O Vite já suporta .ts.

    Tipar unidades evita a classe de erro mais cara em monitoramento: comparar grandezas diferentes.

    Map por GlobalId

    Qual estrutura usar para achar rápido os dados de um elemento pelo seu id?

    Map guarda pares chave-valor e busca em tempo constante. Set guarda valores únicos.

    Com milhares de anomalias, buscar com filter a cada clique fica lento. O Map resolve na hora.

    ?. e ??

    Como ler um campo que pode não existir na resposta da API sem quebrar a tela?

    ?. para a leitura se algo no caminho for nulo. ?? dá um valor padrão só para null ou undefined.

    Sensor com leitura 0 é dado válido. Usar || esconderia essa leitura.

    Datas e números no padrão brasileiro

    Como exibir data, hora e números no formato brasileiro e no fuso certo?

    A API Intl formata conforme o idioma e o fuso, sem bibliotecas.

    Guarde sempre em UTC e formate na exibição. Relatório e gráfico ficam consistentes mesmo com horário de verão.

    O que é React

    O que é React e que problema ele resolve?

    Uma biblioteca para construir interfaces a partir de componentes. Você descreve como a tela deve ficar para cada estado, e o React atualiza o DOM quando o estado muda.

    Com dezenas de painéis reagindo ao mesmo dado do sensor, descrever a tela por estado evita telas fora de sincronia.

    O que é TypeScript

    O que o TypeScript acrescenta ao JavaScript?

    Tipos. Você declara o formato dos dados e o editor aponta erros antes de rodar. No build, o TypeScript vira JavaScript comum.

    Em plataformas com muitas unidades e formatos de dado, os tipos funcionam como uma revisão automática a cada linha digitada.

    Criar o projeto

    Como iniciar uma plataforma React com TypeScript usando Vite?

    O Vite gera o projeto, roda um servidor de desenvolvimento com recarga instantânea e empacota para produção.

    É a mesma base do AstraStruct e do SHM Vision Lab, então tudo deste curso se aplica direto aos dois.

    Componentes e JSX

    O que é um componente React?

    Uma função que devolve JSX, um HTML dentro do JavaScript. Chaves {} inserem expressões.

    Em JSX é className, não class. Nome de componente começa com maiúscula.

    Props tipadas

    Como reaproveitar o mesmo cartão para qualquer elemento?

    Props são os parâmetros do componente. Em TypeScript você declara o formato delas.

    O TypeScript acusa erro se alguém passar nota={7}.

    useState

    Como guardar qual elemento está selecionado no visualizador?

    Estado é um valor que, ao mudar, faz o React redesenhar o componente.

    Nunca altere o estado direto. Sempre crie um valor novo e passe ao set....

    useEffect

    Como buscar as leituras do sensor quando o componente aparece?

    useEffect roda efeitos colaterais (rede, timers) depois de desenhar. A lista de dependências controla quando repete.

    A função de limpeza evita mostrar dados do sensor antigo quando o usuário troca rápido de sensor.

    Listas e key

    Como desenhar a lista de todos os sensores?

    Use map e dê a cada item uma key única e estável.

    Use o id do sensor ou o GlobalId do IFC como key. O índice do array dá erro quando a lista é reordenada.

    Formulário controlado

    Como ligar o campo "limite de alerta" ao estado?

    O valor do input vem do estado e o onChange atualiza o estado.

    e.target.value é sempre string. Converta com Number() antes de comparar com a tensão.

    useRef

    Como dar ao Three.js ou ao OpenCV.js acesso a um canvas criado pelo React?

    useRef guarda uma referência ao elemento real do DOM sem causar novo desenho.

    Sem o dispose, cada troca de tela deixa geometrias presas na memória da placa de vídeo.

    Hook próprio

    Como reaproveitar a lógica de "assinar um sensor" em vários componentes?

    Um hook personalizado é uma função que começa com use e combina outros hooks.

    A tela não sabe se o dado vem de WebSocket ou de polling. Dá para trocar a fonte sem mexer nos componentes.

    Organização

    Como organizar as pastas de uma plataforma de gêmeo digital?

    Separe por responsabilidade: cálculo puro, acesso a dados, 3D e interface.

    calc/ e vision/ não importam React. Assim viram bibliotecas reaproveitáveis entre projetos.

    useMemo

    O painel recalcula estatísticas de 100 mil leituras a cada clique. Como evitar?

    useMemo guarda o resultado de um cálculo e só refaz quando as dependências mudam.

    Use só para cálculos pesados. Para contas simples, o custo do useMemo é maior que o ganho.

    Context

    Visualizador 3D, painel e lista precisam saber qual elemento está selecionado. Como compartilhar?

    Um Context fornece um valor a todos os componentes abaixo dele, sem passar props por cada nível.

    Clicar no 3D, na lista ou no croqui muda o mesmo estado, e todas as partes da tela se atualizam juntas.

    Testes com Vitest

    Como garantir que momentoMax continua certo depois de uma refatoração?

    Vitest roda testes no mesmo ambiente do Vite. Escreva casos com valores conhecidos de cálculo manual.

    Testes de cálculo são a parte mais barata e mais valiosa de testar numa plataforma de engenharia.

    O que é visão computacional

    O que é visão computacional?

    A área que faz computadores extraírem informação de imagens e vídeos: detectar, classificar, segmentar, medir e reconstruir em 3D.

    Na inspeção de OAEs, a visão computacional transforma fotos em medidas objetivas e comparáveis entre campanhas.

    O que é uma imagem digital

    Como uma foto é representada no computador?

    Como uma grade de pixels. Cada pixel guarda números de intensidade: um valor em tons de cinza ou três valores (vermelho, verde, azul), geralmente de 0 a 255.

    Toda técnica do curso, do limiar à U-Net, é uma operação sobre essa grade de números.

    Abrir a foto

    Como ler uma foto escolhida pelo inspetor sem enviá-la a um servidor?

    O arquivo do input type="file" vira um bitmap direto no navegador.

    Processar no navegador mantém fotos de obras sensíveis no dispositivo e funciona sem internet em campo.

    Desenhar no canvas

    Como colocar a foto no canvas, reduzida para processar mais rápido?

    O contexto 2D desenha a imagem. Ao reduzir, guarde a escala para converter medidas de volta.

    Se a escala da foto original é 0,1 mm/px e k = 0,25, no canvas cada px vale 0,4 mm.

    ImageData

    Como os pixels ficam guardados na memória?

    Num array plano Uint8ClampedArray com 4 valores por pixel (R, G, B, A) de 0 a 255, linha por linha.

    Mesma ideia do NumPy (H, W, C), só que achatado. Entender o índice i resolve metade dos bugs.

    Tons de cinza

    Como converter a foto para cinza antes de procurar fissuras?

    Combine os canais com pesos de luminância. O verde pesa mais porque o olho é mais sensível a ele.

    Fissura em concreto aparece como uma linha mais escura que o entorno. O canal de cinza já carrega quase toda a informação.

    Limiarização

    Como separar pixels "candidatos a fissura" do fundo?

    Pixels abaixo de um limiar viram 1 (fissura), os outros 0. O resultado é uma máscara binária.

    Limiar fixo falha com sombra e umidade. Use limiar adaptativo (próximos cartões) ou um modelo treinado.

    Convolução

    Como realçar bordas com o filtro de Sobel?

    Uma convolução passa uma pequena matriz (kernel) por toda a imagem. Sobel mede a variação horizontal e vertical.

    É a mesma operação que as camadas de uma CNN aprendem sozinhas. Escrever uma à mão ajuda a entender a U-Net.

    OpenCV.js

    Como usar OpenCV no navegador em vez de escrever cada filtro?

    OpenCV.js é o OpenCV compilado para WebAssembly. A API lembra a do Python, mas a memória é manual.

    Esqueceu o .delete()? A memória do WebAssembly cresce a cada foto até a aba travar.

    Morfologia

    Como fechar falhas na máscara e remover pontinhos de ruído?

    Fechamento (dilatar e depois erodir) une trechos quebrados. Abertura (erodir e depois dilatar) remove ruído pequeno.

    Esse pós-processamento é útil também depois de um modelo de deep learning, para limpar a máscara prevista.

    Medir a fissura

    Como sair da máscara em pixels para comprimento em mm?

    Encontre os contornos, meça em pixels e multiplique pela escala (mm/px) obtida com um alvo de referência na foto.

    Metade do perímetro é só uma aproximação. Para comprimento e largura confiáveis use o esqueleto (curso de Python).

    ONNX no navegador

    Como rodar no navegador a U-Net que você treinou em PyTorch?

    Exporte para ONNX (curso 9) e rode com ONNX Runtime Web. O tensor de entrada segue o formato [1, 3, H, W].

    Use a mesma normalização do treino (por exemplo, média e desvio do ImageNet). Diferença aqui derruba o IoU sem nenhum erro aparente.

    Máscara sobre a foto

    Como transformar a saída do modelo numa máscara vermelha semitransparente?

    Aplique a sigmoide aos logits, corte em 0,5 e pinte os pixels no segundo canvas.

    Confira se o modelo já sai com sigmoide. Aplicar duas vezes deixa quase tudo acima de 0,5.

    Web Worker

    A inferência trava a interface por 2 s. Como resolver?

    Rode o processamento num Web Worker, uma thread separada. A tela continua respondendo.

    É o mesmo padrão que os visualizadores IFC usam para carregar modelos grandes sem congelar a tela.

    Orientação da foto

    A foto do celular aparece deitada no canvas. Por quê?

    Celulares gravam a foto em uma posição e indicam a rotação nos metadados EXIF. Peça ao navegador para aplicar essa orientação ao decodificar.

    Se a orientação estiver errada, a escala calibrada no eixo x passa a valer no eixo y e as medidas ficam trocadas.

    Realce de contraste

    A foto sob o tabuleiro está escura e sem contraste. Como realçar antes de segmentar?

    Esticar o histograma leva os valores entre o percentil 1% e 99% para 0 a 255. O CLAHE do OpenCV faz isso por regiões.

    Aplique o mesmo realce no treino e na inferência. Realce só na inferência muda a distribuição que o modelo aprendeu.

    Imagens grandes em blocos

    A foto tem 6000 × 4000 px e o modelo aceita 512 × 512. Como processar sem perder fissuras finas?

    Divida em blocos com sobreposição, rode o modelo em cada um e recomponha a máscara, usando o máximo nas áreas sobrepostas.

    Reduzir a foto inteira para 512 px faria uma fissura de 0,3 mm desaparecer. Blocos mantêm a resolução original.

    O que é Python

    Por que Python domina a pesquisa em visão computacional e ciência de dados?

    É uma linguagem de leitura simples com um ecossistema enorme: NumPy, OpenCV, scikit-image, pandas, PyTorch. As partes pesadas dessas bibliotecas rodam em C/C++ e na GPU.

    O fluxo da trilha: pesquisar e treinar em Python, entregar no navegador em JavaScript.

    Clássica ou deep learning?

    Qual a diferença entre visão computacional clássica e deep learning?

    Na clássica, você escolhe as regras (limiar, filtro, morfologia). No deep learning, a rede aprende as regras a partir de exemplos anotados.

    Os dois se completam: a rede segmenta, e o processamento clássico limpa a máscara e mede em mm.

    O que é segmentação

    O que significa segmentar uma imagem?

    Atribuir um rótulo a cada pixel, separando o que interessa (fissura, mancha, armadura) do fundo (concreto são). O resultado é uma máscara do mesmo tamanho da foto.

    Para o laudo, a caixa diz onde olhar; a máscara diz quanto mede.

    Etapas da segmentação

    Quais são as etapas de um pipeline de segmentação de manifestações patológicas?

    Da foto ao laudo, cada etapa entrega algo à próxima. Clássico e deep learning mudam só a etapa 3; o resto é igual.

    Quando o resultado sai ruim, descubra em qual etapa o erro nasceu. Melhorar a rede não resolve uma foto sem escala.

    O que é uma máscara

    O que é uma máscara e como ela é guardada?

    Uma imagem do mesmo tamanho da foto em que cada pixel diz a que classe pertence. Na binária, 0 é fundo e 1 (ou 255) é objeto. Na multiclasse, cada valor inteiro é uma classe.

    Salve máscaras em PNG. O JPG cria valores intermediários nas bordas e uma máscara 0/1 vira 0, 1, 2, 7... sem sentido.

    O que é o histograma

    O que o histograma de uma foto em tons de cinza mostra?

    Quantos pixels existem com cada intensidade de 0 a 255. Numa foto de fissura em concreto, aparece um pico grande (concreto claro) e uma cauda ou pico pequeno de pixels escuros (fissura).

    Se o histograma não tem dois grupos separados (sombra forte, manchas), nenhum limiar global vai funcionar bem.

    O que é o método de Otsu

    Como o Otsu escolhe o limiar sozinho?

    Ele testa todos os limiares de 0 a 255 e escolhe o que melhor separa o histograma em duas classes: máxima variância entre as classes, o que equivale à mínima variância dentro de cada uma. Foi proposto por Nobuyuki Otsu em 1979.

    Otsu sempre devolve um limiar, mesmo numa foto sem fissura. Ele separa a imagem em duas classes, existindo ou não um defeito.

    Limiar global ou adaptativo?

    Quando o limiar único do Otsu falha e o que usar no lugar?

    O limiar global usa um valor para a foto inteira. O adaptativo calcula um limiar para cada vizinhança, a partir da média local, e resiste a sombra e iluminação desigual.

    A janela do adaptativo deve ser bem maior que a largura da fissura em pixels. Janela pequena demais marca a textura do concreto inteira.

    O que é morfologia matemática

    O que fazem erosão, dilatação, abertura e fechamento?

    São operações sobre a forma da máscara, usando um pequeno elemento estruturante (quadrado, cruz ou elipse) que percorre a imagem.

    Morfologia muda a largura. Meça a abertura da fissura na máscara antes da erosão ou da dilatação, ou compense o efeito.

    Descritores de forma

    Como o computador diferencia uma fissura de uma mancha pela forma?

    Cada região da máscara é descrita por números: área, alongamento, circularidade, solidez, orientação. Uma fissura é longa e fina; uma mancha é compacta.

    A orientação também informa: fissuras verticais no meio do vão e inclinadas perto do apoio sugerem mecanismos diferentes, que o engenheiro interpreta.

    Classificar patologias por regras

    Como separar fissura, eflorescência e armadura exposta sem deep learning?

    Combine forma e cor numa árvore de regras. A cor em HSV (matiz, saturação, valor) separa melhor que RGB: eflorescência é clara e sem saturação; corrosão tem matiz marrom-avermelhado.

    Regras são transparentes e boas para um primeiro protótipo, mas quebram com iluminação e concreto diferentes. Os casos que elas erram viram dados de treino para a rede.

    Separação em camadas

    Como guardar e mostrar cada patologia em uma camada própria?

    Duas formas. O mapa de rótulos (H × W) admite uma classe por pixel. A pilha de máscaras (H × W × C), uma camada por patologia, permite sobreposição, como uma fissura dentro de uma mancha de umidade.

    Camadas separadas permitem ligar e desligar cada patologia no visualizador e medir cada uma sem interferência das outras.

    Como isolar as bibliotecas de cada projeto de pesquisa?

    Um ambiente virtual guarda versões próprias de pacotes. O requirements.txt registra quais são.

    Anexar o requirements.txt ao artigo é o mínimo para alguém reproduzir seus resultados.

    NumPy e imagens

    Qual é o formato de uma foto colorida carregada em Python?

    Um array NumPy com forma (altura, largura, canais) e tipo uint8 de 0 a 255.

    Recortar em janelas (tiles) de 512×512 é o primeiro passo para treinar redes com fotos de alta resolução.

    Por que nunca percorrer pixels com for em Python?

    Aqui a lógica é o contrário do JavaScript: no JS o laço for é rápido; em Python, vetorize.

    O imread não dá erro com caminho errado: devolve None. Sempre verifique.

    Suavizar e binarizar

    Como obter uma máscara de fissura sem escolher o limiar à mão?

    Suavize para reduzir a textura do concreto e use Otsu, que calcula o limiar pelo histograma.

    Otsu funciona quando o histograma tem dois picos. Em concreto manchado, compare com o adaptativo.

    Morfologia e Canny

    Como limpar a máscara e extrair bordas?

    A área mínima deve ser definida em mm² e convertida para px com a escala da foto.

    Esqueleto e largura

    Como medir comprimento e abertura máxima de uma fissura?

    O esqueleto dá a linha central (comprimento). A transformada de distância dá a meia-largura em cada ponto dessa linha.

    Contar pixels do esqueleto subestima trechos diagonais em até cerca de 40%. Para artigo, some √2 nas diagonais.

    Como converter medidas em pixel para milímetros com confiança?

    Fotografe um alvo de dimensão conhecida no mesmo plano da fissura e meça-o em pixels.

    A escala vale só para o plano do alvo. Foto oblíqua sem retificação gera erro que cresce ao longo da imagem.

    O que é deep learning

    Como deep learning se relaciona com inteligência artificial e machine learning?

    São conjuntos dentro de conjuntos. Deep learning é o machine learning feito com redes neurais de muitas camadas, que aprendem sozinhas as características relevantes dos dados brutos (pixels, sinais).

    No ML tradicional, o engenheiro define as características (área, comprimento, contraste). No deep learning, a rede as descobre a partir das fotos anotadas.

    O que é uma rede neural

    O que um neurônio artificial calcula?

    Uma soma ponderada das entradas mais um viés, passada por uma função de ativação. Uma rede empilha milhares desses neurônios em camadas.

    "Treinar" é ajustar milhões de pesos w até a rede acertar os exemplos. O arquivo .pt guarda exatamente esses pesos.

    O que é uma CNN

    Por que redes convolucionais funcionam bem com imagens?

    Elas aplicam pequenos filtros (kernels) que deslizam pela imagem, como o Sobel, mas com valores aprendidos. As primeiras camadas detectam bordas; as seguintes combinam bordas em texturas e formas.

    É a mesma convolução do cartão de Sobel no curso de JS para visão computacional, repetida em dezenas de camadas.

    Como a rede aprende

    O que acontece em cada passo do treino?

    A rede prevê, a função de perda mede o erro em relação à anotação, a retropropagação calcula como cada peso influenciou o erro e o otimizador ajusta os pesos um pouco na direção que reduz o erro.

    Se a perda do treino cai e a da validação sobe, a rede está decorando o treino (overfitting). É hora de mais dados ou mais aumento de dados.

    Semântica, instância e panóptica

    Quais são os tipos de segmentação feitos por redes neurais?

    A semântica rotula cada pixel por classe. A de instância separa cada objeto individual com sua máscara. A panóptica junta as duas.

    Uma rede semântica seguida de componentes conectados também separa instâncias, desde que as fissuras não se toquem.

    Estrutura da U-Net

    Como é a arquitetura da U-Net e por que ela é boa para fissuras finas?

    Um encoder reduz a imagem e extrai contexto; um decoder reconstrói a resolução. As conexões de atalho (skip connections) levam os detalhes finos do encoder direto ao decoder. Foi proposta por Ronneberger et al. em 2015, para imagens biomédicas.

    Sem os atalhos, a fissura de 2 px de largura se perderia na redução para 32 × 32.

    O que é YOLO

    O que é o YOLO e por que ele é rápido?

    You Only Look Once: uma família de detectores que prevê todas as caixas e classes num único passe da rede pela imagem. Foi proposto por Redmon et al. em 2016; as versões mais usadas hoje vêm da biblioteca Ultralytics.

    Rodar em tempo real permite usar o YOLO no vídeo do drone durante o voo, marcando as regiões que merecem foto de perto.

    Estrutura do YOLO

    Quais são as três partes da arquitetura do YOLO?

    Backbone, neck e head. O backbone extrai características; o neck combina características de escalas diferentes; o head faz as previsões em várias escalas.

    As três escalas explicam por que o YOLO acha tanto um desplacamento grande quanto uma armadura exposta pequena na mesma foto.

    Como o YOLO gera máscaras

    Como o YOLO-seg produz uma máscara para cada objeto?

    A rede gera um conjunto de máscaras-protótipo para a imagem inteira e, para cada objeto detectado, um vetor de coeficientes. A máscara do objeto é a combinação dos protótipos com esses coeficientes, recortada pela caixa.

    Os protótipos têm resolução menor que a foto. Para aberturas de décimos de milímetro, combine o YOLO com uma U-Net de alta resolução dentro da caixa.

    IoU e NMS

    O que são IoU de caixas e supressão de não máximos (NMS)?

    IoU mede a sobreposição de duas caixas: área da interseção dividida pela área da união. O NMS mantém a caixa de maior confiança e descarta as outras da mesma classe que a sobrepõem acima de um limiar de IoU.

    Fissuras longas e ramificadas geram várias caixas sobrepostas. Ajuste o limiar de IoU do NMS ou prefira a segmentação semântica para elas.

    Ler a saída do YOLO

    Onde ficam caixas, classes, confianças e máscaras no resultado do Ultralytics?

    Cada imagem gera um objeto de resultado com boxes e, nos modelos de segmentação, masks.

    Para medir, use r.masks.xy (coordenadas da foto original) ou redimensione masks.data para o tamanho da foto antes de aplicar a escala mm/px.

    Estrutura do Mask R-CNN

    Como o Mask R-CNN segmenta instâncias e em que difere do YOLO?

    É um detector de duas etapas (He et al., 2017). Uma rede de propostas (RPN) sugere regiões; o RoIAlign recorta as características de cada região; três cabeças preveem classe, caixa refinada e uma máscara por região.

    Mask R-CNN continua forte em datasets pequenos de patologias, enquanto o YOLO-seg ganha quando a velocidade importa.

    Classificação de patologias com redes

    Como organizar as classes de manifestações patológicas para treinar uma rede?

    Defina uma taxonomia fechada, com critério escrito para cada classe, e decida se uma região pode ter mais de um rótulo. Classes ambíguas ou raras demais confundem a rede.

    Alinhe os nomes das classes com os termos usados no laudo e na NBR 9452, para a saída da rede entrar direto no relatório.

    Qual tarefa?

    Classificação, detecção, segmentação semântica ou de instância: qual usar para fissuras?

    Depende da pergunta. Para medir abertura é preciso saber quais pixels são fissura, ou seja, segmentação.

    Um pipeline comum: detecção para achar a região e segmentação dentro da caixa para medir.

    Anotação e formatos

    Em que formato guardar as anotações do seu dataset?

    Cada família de modelo espera um formato. Converta a partir de uma fonte única de verdade.

    Anote em polígonos (CVAT, Label Studio). Polígono gera máscara e caixa; caixa nunca vira máscara.

    Dividir sem vazar

    Por que o modelo tem 95% no teste e falha numa ponte nova?

    Quase sempre por vazamento: janelas da mesma foto ou da mesma obra estão no treino e no teste.

    Separar por obra é o que permite afirmar no artigo que o método generaliza para novas pontes.

    Dataset PyTorch

    Como entregar pares imagem-máscara ao treino?

    Uma classe Dataset com __len__ e __getitem__. O DataLoader monta os lotes.

    Leia sempre a máscara como binária (> 0). Máscaras salvas como 255 ou 1 devem dar o mesmo resultado.

    Aumento de dados

    Como multiplicar um dataset pequeno sem desalinhar imagem e máscara?

    albumentations aplica a mesma transformação geométrica aos dois.

    Variações de brilho imitam inspeções em horários diferentes. Escolha aumentos que reflitam o campo real.

    Tensores e GPU

    Como garantir que o treino roda na placa de vídeo?

    Modelo e dados precisam estar no mesmo device. Tensores de imagem seguem o formato (N, C, H, W).

    Erro "expected CUDA but got CPU" significa que algo ficou fora do .to(device).

    U-Net pronta

    Como montar uma U-Net com encoder pré-treinado em uma linha?

    segmentation_models_pytorch oferece U-Net, DeepLabV3+ e outras com encoders do ImageNet.

    Com poucas centenas de imagens, o encoder pré-treinado é o que torna o treino viável.

    Função de perda

    Fissura ocupa 2% dos pixels. Por que a BCE sozinha falha?

    O modelo aprende a prever "tudo fundo" e acerta 98%. A Dice mede sobreposição e não é dominada pelo fundo.

    Combinar Dice e BCE é comum em segmentação de fissuras. Focal loss é outra opção para classes raras.

    Laço de treino

    Quais são os passos de cada iteração de treino?

    Prever, calcular a perda, zerar gradientes, retropropagar, atualizar os pesos.

    Salve o melhor modelo pela validação, não o da última época. Registre a semente aleatória para reproduzir.

    Métricas

    Quais métricas reportar para segmentação de fissuras?

    IoU e F1 (Dice) por pixel, mais precisão e recall para mostrar o tipo de erro.

    Em inspeção, recall baixo é mais grave: é fissura que ninguém viu. Discuta o limiar com esse critério.

    YOLO para segmentação

    Como treinar um modelo de segmentação de instância com pouco código?

    A biblioteca Ultralytics treina YOLO de detecção e segmentação a partir de um arquivo YAML do dataset.

    Bom para várias classes de manifestação patológica. Para medir aberturas finas, uma U-Net em alta resolução costuma ser mais precisa.

    Exportar para a web

    Como levar o modelo treinado para a plataforma no navegador?

    Exporte para ONNX com um tensor de exemplo e eixos dinâmicos. Depois rode com ONNX Runtime Web (curso 7).

    Fecha o ciclo: treino em Python, inferência no navegador do inspetor, resultado ligado ao elemento no gêmeo digital.

    Congelar o encoder

    Com só 200 imagens anotadas, como evitar que o modelo decore o treino?

    Treine primeiro só o decoder, com o encoder pré-treinado congelado. Depois libere tudo com taxa de aprendizado menor.

    É a mesma ideia do funil de transferência de domínio: genérico, depois concreto, depois as suas pontes.

    Precisão mista

    Como treinar mais rápido e com lotes maiores na mesma GPU?

    Precisão mista faz parte das contas em 16 bits. torch.autocast escolhe onde é seguro e o GradScaler evita gradientes que somem.

    Em GPUs recentes o ganho de velocidade costuma ser grande. Confira se as métricas finais não mudam em relação ao treino em 32 bits.

    Incerteza com MC Dropout

    Como saber em quais pixels o modelo está inseguro?

    Mantenha o dropout ligado na inferência, rode várias vezes e meça a variação entre as previsões.

    Mostrar a incerteza ao inspetor indica onde a foto precisa de verificação humana antes de entrar no laudo.

    O que é SHM

    O que é monitoramento da integridade estrutural (SHM)?

    Structural Health Monitoring: acompanhar o comportamento de uma estrutura ao longo do tempo com sensores, para detectar e avaliar danos e apoiar decisões de manutenção.

    A inspeção visual periódica (NBR 9452) e o SHM contínuo se completam: um dá o estado detalhado em datas, o outro dá a evolução entre elas.

    O que é pós-processamento

    Por que os dados dos sensores precisam de pós-processamento?

    O sinal bruto mistura resposta da estrutura, ruído elétrico, efeitos de temperatura e falhas de aquisição. O pós-processamento limpa, transforma e resume o sinal em indicadores: frequências, amortecimento, tendências e alertas.

    Uma queda persistente da frequência natural, depois de descontada a temperatura, pode indicar perda de rigidez.

    Vetores e matrizes

    O que muda ao sair do Python e do JavaScript para o MATLAB?

    Tudo é matriz, a indexação começa em 1 e as operações elemento a elemento levam ponto: .*, ./, .^.

    Esquecer o ponto em .* é o erro mais comum de quem vem de outra linguagem: dá erro de dimensão ou um resultado errado.

    Importar dados

    Como ler o CSV exportado pelo sistema de aquisição?

    readtable lê o arquivo numa tabela com colunas nomeadas. datetime converte o tempo.

    Confira se as amostras têm espaçamento constante (diff do tempo). Falhas de aquisição criam lacunas que distorcem a FFT.

    Scripts e funções

    Como organizar o pós-processamento para reutilizar em todas as campanhas?

    Um script roda passos em sequência. Uma função fica em arquivo próprio com o mesmo nome e recebe parâmetros.

    Live Scripts (.mlx) misturam texto, código e gráficos. Servem como caderno de laboratório da campanha.

    Gráficos para artigo

    Como gerar uma figura limpa em 300 dpi?

    Use plot com rótulos e unidades, ajuste o tamanho e exporte com exportgraphics.

    8,5 cm é a largura de uma coluna na maioria dos periódicos. Desenhe já no tamanho final para a fonte não encolher.

    Tendência e outliers

    O sinal tem deriva lenta e picos espúrios. Como limpar?

    detrend remove tendência linear. isoutlier e filloutliers tratam picos isolados.

    Em extensômetros, a deriva pode ser térmica e ter significado físico. Separe o que é efeito ambiental do que é ruído antes de remover.

    Filtragem

    Como filtrar o acelerômetro sem atrasar os picos no tempo?

    Projete um Butterworth e aplique com filtfilt, que filtra ida e volta e anula a defasagem.

    butter e filtfilt são da Signal Processing Toolbox. No GNU Octave, o pacote signal tem as mesmas funções.

    FFT

    Como ver em que frequências a ponte vibra?

    A FFT leva o sinal ao domínio da frequência. A resolução é fs/N: medir por mais tempo dá picos mais finos.

    Com 10 minutos a 200 Hz, a resolução é cerca de 0,0017 Hz. Isso basta para acompanhar a variação da primeira frequência ao longo do ano.

    Welch e picos

    O espectro da FFT está ruidoso. Como estimar melhor as frequências?

    O método de Welch divide o sinal em janelas, calcula vários espectros e faz a média. findpeaks localiza os picos.

    Janelas maiores melhoram a resolução, janelas menores reduzem a variância. Reporte a escolha na metodologia.

    Amortecimento

    Como estimar a razão de amortecimento de um modo a partir do espectro?

    Pelo método da meia potência: ξ ≈ (f2 − f1) / (2 fn), onde f1 e f2 cruzam o nível do pico dividido por √2 (em amplitude).

    Meia potência é sensível à resolução. Para identificação modal de pesquisa, use métodos como SSI ou EFDD e compare.

    Efeito da temperatura

    A frequência natural muda ao longo do ano. Como separar efeito ambiental de dano?

    Ajuste um modelo frequência × temperatura num período de referência e acompanhe o resíduo. Um resíduo fora da faixa normal é o alerta.

    É a base de muitos sistemas de detecção de dano por vibração. fitlm é da Statistics and Machine Learning Toolbox.

    Ligar à plataforma

    Como mandar os resultados do MATLAB para a plataforma web?

    Exporte em JSON ou CSV para a API, ou chame o MATLAB a partir do Python com o MATLAB Engine.

    O JSON entra no gêmeo pelo mesmo caminho dos sensores (curso 5). O fn e o alerta aparecem no elemento IFC correspondente.

    timetable

    Como alinhar sensores com taxas de amostragem diferentes?

    Uma timetable é uma tabela indexada pelo tempo. retime e synchronize reamostram e alinham séries.

    É o passo que permite cruzar frequência natural com temperatura no modelo do curso.

    Espectrograma

    Como ver se o conteúdo de frequência muda durante a passagem de um caminhão?

    O espectrograma calcula espectros em janelas sucessivas e mostra frequência × tempo × energia.

    Útil para separar trechos de vibração ambiente dos eventos de tráfego antes de identificar os modos.

    Validação de argumentos

    Como evitar que alguém chame a função com fs negativo ou um vetor vazio?

    O bloco arguments declara tipos, tamanhos e restrições, com mensagem de erro clara.

    Erros de unidade e de formato aparecem na chamada, e não como um espectro estranho três funções depois.

    O que é BIM

    O que significa BIM e por que não é só um modelo 3D?

    Building Information Modeling: um processo de projetar, construir e operar com um modelo digital em que cada objeto tem geometria e informação (material, propriedades, fases, custos, manutenção). O 3D é só uma das formas de ver essa informação.

    BIM não é um software. Revit, Tekla, Allplan e outros são ferramentas que produzem modelos BIM; o IFC é o formato aberto de troca entre elas.

    BIM ou CAD?

    Qual a diferença prática entre trabalhar em CAD e em BIM?

    No CAD você desenha linhas que representam a ponte. No BIM você modela os elementos da ponte, e plantas, cortes e quantitativos saem do mesmo modelo.

    Para o gêmeo digital, o que importa é a informação por objeto: é nela que se penduram anomalias, sensores e notas de condição.

    Dimensões do BIM

    O que são 4D, 5D e as demais "dimensões" do BIM?

    São usos que acrescentam informação ao modelo 3D. A partir da 6D, a definição varia entre autores e países.

    O monitoramento de uma ponte em serviço fica na fase de operação e manutenção, que é onde o modelo BIM passa a alimentar o gêmeo digital.

    BIM nas obras públicas

    O uso de BIM em obras públicas no Brasil é regulamentado?

    Sim. A Estratégia BIM BR e o Decreto nº 10.306/2020 estabeleceram a adoção gradual do BIM em obras e serviços de engenharia da administração pública federal, em fases que vão do projeto à gestão do ativo.

    Confira no texto do decreto e nas normas atualizadas do órgão contratante quais fases e entregas já são exigidas no seu projeto.

    O que é gêmeo digital

    O que define um gêmeo digital?

    Uma representação virtual de um ativo físico específico, ligada a ele por dados que chegam de forma contínua ou periódica, e usada para acompanhar, prever e decidir. O gêmeo muda quando a ponte muda.

    Um modelo 3D bonito sem dados atualizados é uma maquete digital. O que faz dele um gêmeo é o fluxo de dados com a estrutura real.

    Modelo, sombra e gêmeo

    Qual a diferença entre modelo digital, sombra digital e gêmeo digital?

    Uma classificação muito usada (Kritzinger et al., 2018) olha para a direção e a automação do fluxo de dados entre o ativo físico e o digital.

    Em pontes, a maior parte das aplicações reais é sombra digital: os dados entram automaticamente e a decisão continua com o engenheiro. Isso é desejável.

    BIM ou gêmeo digital?

    Um modelo BIM já é um gêmeo digital?

    Não. O BIM descreve a ponte como projetada ou construída. O gêmeo digital acompanha a ponte como ela está hoje, alimentado por medições. O BIM costuma ser a base geométrica e de informação do gêmeo.

    Muitas pontes antigas não têm BIM. Nelas, a nuvem de pontos da fotogrametria vira a base do gêmeo, e o modelo BIM é construído a partir dela.

    O que é IFC

    Por que usar IFC como base do gêmeo digital de uma OAE?

    IFC é o formato aberto de BIM (ISO 16739). Guarda geometria e significado: cada objeto sabe se é laje, viga ou pilar e carrega propriedades.

    Um formato aberto evita depender de um único software proprietário durante os 50 a 100 anos de vida da ponte.

    IFC 4.3 e pontes

    O IFC tem entidades próprias para pontes?

    Sim. O IFC 4.3 incluiu infraestrutura: IfcBridge, IfcBridgePart, alinhamentos e tipos como IfcBearing (aparelho de apoio).

    Essa árvore espelha a divisão em elementos que as inspeções seguem, o que facilita ligar laudo e modelo.

    GlobalId

    Qual chave liga um sensor ou uma anomalia ao elemento do modelo?

    Todo objeto IFC tem um GlobalId único de 22 caracteres. Ele não muda quando o modelo é reexportado.

    Use o GlobalId, nunca o nome ("Longarina V1"), que alguém pode renomear no software de projeto.

    Instalar o visualizador

    Quais pacotes formam a base de um visualizador IFC na web?

    Os pacotes @thatopen formam um engine IFC open source sobre Three.js. web-ifc lê o arquivo; fragments é o formato rápido de exibição.

    Fixe as versões no package.json. A biblioteca evolui rápido e a API muda entre versões principais.

    Criar o mundo

    Como montar cena, câmera e renderizador do visualizador IFC?

    Um World agrupa os três. É a mesma ideia do Three.js puro, já com controles de órbita.

    Em React, chame isso dentro de um useEffect com useRef no container (curso 6).

    Fragments e worker

    Como o modelo IFC aparece sem travar a tela?

    O FragmentsManager processa o modelo num Web Worker e entrega os objetos prontos para a cena.

    É o mesmo padrão do cartão de Web Worker no curso 7: trabalho pesado fora da thread da interface.

    Carregar o IFC

    Como abrir o arquivo .ifc da ponte no navegador?

    Configure o IfcLoader com o WebAssembly do web-ifc e passe os bytes do arquivo.

    A versão do WASM precisa casar com a do pacote web-ifc instalado. Confira na documentação da sua versão.

    Juntar tudo

    Qual é o fluxo completo do gêmeo digital que você está construindo?

    Cada curso da trilha cobre uma etapa deste fluxo.

    O GlobalId é o ponto de encontro entre visão computacional, monitoramento e BIM.

    Para continuar

    Onde aprofundar depois desta trilha?

    A documentação do engine IFC tem tutoriais executáveis de cada componente: seleção, propriedades, cortes, medidas.

    Próximo passo natural: selecionar um elemento no 3D, ler o GlobalId e abrir no painel as fotos e leituras ligadas a ele.

    Conjuntos de propriedades

    Onde ficam material, nota de condição e data da inspeção num elemento IFC?

    Em conjuntos de propriedades (Psets) ligados ao elemento. O padrão define Psets comuns e você pode criar os seus.

    Prefixe os Psets próprios com um nome do projeto para não confundir com os padrões da buildingSMART.

    IFC em Python

    Como ler elementos e propriedades do IFC no backend?

    A biblioteca ifcopenshell lê e escreve IFC em Python, útil para gerar relatórios e alimentar o banco de dados.

    O mesmo GlobalId lido aqui é o que o visualizador web devolve no clique. Backend e frontend falam a mesma chave.

    Georreferência

    Como colocar o modelo IFC no lugar certo do mapa e alinhado à nuvem de pontos?

    O IFC 4 permite declarar a conversão das coordenadas locais do projeto para um sistema de referência (EPSG) com IfcMapConversion e IfcProjectedCRS.

    Com o IFC e a nuvem no mesmo sistema EPSG, o alinhamento vira uma transformação conhecida em vez de um ajuste manual.

    O que é fotogrametria

    O que é fotogrametria?

    A ciência de obter medidas e modelos 3D a partir de fotografias. Com o mesmo ponto visto em fotos tiradas de posições diferentes, a posição dele no espaço é calculada por triangulação.

    Fotogrametria (medir com fotos) não é o mesmo que fotometria, que é a medição da luz. Os termos parecem, mas são áreas distintas.

    Do pixel ao ponto 3D

    Como duas fotos permitem calcular a profundidade de um ponto?

    Pela paralaxe: o mesmo ponto aparece em posições diferentes nas duas imagens. Quanto mais próximo o objeto, maior o deslocamento. No caso simples de duas câmeras paralelas, Z = f·B/d.

    É por isso que sobreposição e ângulos variados importam: sem paralaxe suficiente, a profundidade fica mal determinada.

    O que é uma nuvem de pontos

    O que guarda uma nuvem de pontos?

    Um conjunto de pontos com coordenadas X, Y, Z, muitas vezes com cor e normal. Ela registra a forma real da superfície, mas não sabe o que é viga ou pilar.

    Dar significado aos pontos (este trecho é a longarina V1) é a ponte entre a nuvem e o modelo BIM do gêmeo digital.

    Fotogrametria ou LiDAR?

    Quando usar fotogrametria e quando usar laser scanner (LiDAR)?

    A fotogrametria calcula a geometria a partir de fotos. O LiDAR mede distâncias diretamente com pulsos de laser. Cada um tem vantagens.

    Fotos permitem segmentar fissuras com deep learning e depois projetá-las no 3D, o que o LiDAR sozinho não oferece.

    GSD

    A que distância voar o drone para enxergar fissuras de 0,3 mm?

    O GSD (ground sample distance) é o tamanho de um pixel na superfície. Depende da distância, do tamanho do pixel do sensor e da focal.

    Fissura fina pede captura próxima (1 a 3 m). Para o modelo geral da OAE, 10 a 20 m bastam. São duas campanhas distintas.

    Sobreposição

    Quanto as fotos precisam se sobrepor para a reconstrução funcionar?

    A fotogrametria casa pontos entre fotos vizinhas. Cada ponto precisa aparecer em várias imagens, de ângulos diferentes.

    Sob o tabuleiro o GPS falha. Planeje voo manual ou câmera em haste e alvos de controle visíveis.

    Reconstrução SfM-MVS

    Como sair de centenas de fotos para uma nuvem de pontos densa?

    Structure from Motion estima as poses das câmeras e uma nuvem esparsa. Multi-View Stereo densifica. COLMAP e OpenDroneMap são abertos.

    Guarde as poses das câmeras, além da nuvem. Elas permitem levar a máscara 2D de cada foto para o 3D (módulo 3).

    Escala real

    A nuvem saiu sem unidade. Como colocá-la em metros?

    SfM só com fotos reconstrói a forma, mas não o tamanho. Use alvos de controle (GCPs) ou uma distância medida em campo.

    Use pelo menos três distâncias de verificação, não usadas no ajuste, e reporte o erro. É o que o revisor vai perguntar.

    Formatos de nuvem

    PLY, LAS, E57: qual formato usar?

    PLY é simples e comum em fotogrametria. LAS/LAZ é o padrão de LiDAR e geoespacial. E57 é o padrão de scanners terrestres.

    Nuvem de laser scanner e nuvem de fotogrametria da mesma ponte se complementam. O registro do módulo 2 junta as duas.

    Open3D: abrir e ver

    Como inspecionar a nuvem em Python?

    Open3D lê, processa e visualiza nuvens e malhas. Os pontos ficam acessíveis como array NumPy.

    Olhe a caixa delimitadora: se o vão de 25 m aparece como 2,5, a escala está errada.

    Reduzir e limpar

    A nuvem tem 18 milhões de pontos e ruído flutuando. O que fazer primeiro?

    Reduza com uma grade de voxels e remova pontos isolados com o filtro estatístico.

    Mantenha a nuvem completa para medir anomalias. Use a reduzida para registro, segmentação e visualização web.

    Normais e planos

    Como isolar o plano do tabuleiro e medir o desvio dos pontos em relação a ele?

    RANSAC ajusta um plano ignorando pontos fora dele. A distância de cada ponto ao plano mostra flechas e irregularidades.

    As normais também ajudam a separar faces de vigas e pilares por orientação antes da segmentação por elemento.

    Registro ICP

    Como alinhar a nuvem de 2026 com a de 2025 para comparar?

    ICP refina iterativamente a transformação rígida entre duas nuvens. Precisa de um alinhamento inicial razoável.

    Registre usando regiões que não mudam (pilares, encontros). Se usar a região deformada, o ICP "esconde" a deformação.

    Detectar mudanças

    Como achar onde o concreto desplacou entre duas campanhas?

    Calcule a distância de cada ponto da nuvem nova à antiga e pinte por faixa de valor.

    O limiar de mudança deve ficar acima do erro do registro (inlier_rmse). Abaixo disso é ruído, não dano.

    Máscara 2D no 3D

    Como marcar na nuvem os pontos que a U-Net segmentou como fissura numa foto?

    Projete cada ponto 3D na foto com o modelo de câmera pinhole (K, R, t vindos do SfM) e leia a máscara no pixel correspondente.

    Este passo dá posição 3D à fissura: em qual elemento está e a que distância do apoio. Trate oclusão com um teste de profundidade.

    Da nuvem para a web

    Como levar o resultado para o visualizador do gêmeo digital?

    Gere uma malha leve para o Three.js ou publique a nuvem em níveis de detalhe para nuvens muito grandes.

    Para alinhar com o IFC (curso 11), leve a nuvem ao sistema de coordenadas do modelo e guarde a matriz de transformação junto com a campanha.

    Coordenadas grandes

    A nuvem em UTM treme e fica "quadriculada" no visualizador web. Por quê?

    GPUs trabalham em float32, que tem cerca de 7 dígitos. Coordenadas como 7 394 120,123 m perdem os milímetros. Subtraia uma origem local e guarde o deslocamento.

    Use a mesma origem para nuvem, malha e IFC. Senão, o alinhamento no visualizador se perde.

    Recortar e medir

    Como isolar um pilar da nuvem e medir suas dimensões principais?

    Recorte com uma caixa e calcule a caixa orientada ou a análise de componentes principais (PCA) dos pontos.

    Comparar as dimensões medidas com as do projeto é uma checagem rápida da escala da reconstrução.

    Nuvens enormes na web

    Como mostrar no navegador uma nuvem de 200 milhões de pontos?

    Converta para um formato em níveis de detalhe (octree), que carrega só os pontos visíveis na resolução necessária. Potree e 3D Tiles são as opções mais usadas.

    O CesiumJS citado na especificação do backend lê 3D Tiles e coloca a ponte no globo com o terreno ao redor.

    VR, AR, MR e XR

    Qual a diferença entre realidade virtual, aumentada, mista e estendida?

    Elas se diferenciam pelo quanto do mundo real o usuário continua vendo e se o conteúdo virtual interage com ele.

    No gêmeo digital, VR serve ao planejamento e à revisão em equipe, e AR à inspeção em campo.

    VR, AR e WebXR

    O que é WebXR e o que precisa para usar?

    WebXR é a API do navegador para realidade virtual (imersão total) e aumentada (sobre o mundo real). Roda no navegador de headsets como os da linha Meta Quest, sem instalar app.

    Em VR, o inspetor percorre o tabuleiro e o interior das longarinas celulares antes de ir a campo, ou revisa a inspeção com a equipe.

    Ativar o modo VR

    O que acrescentar a uma cena Three.js para ela abrir no headset?

    Habilite o XR no renderizador, adicione o botão de entrada e use setAnimationLoop no lugar de requestAnimationFrame.

    A cena do curso 5 já usa setAnimationLoop, então basta acrescentar essas três linhas.

    Escala real

    Por que 1 unidade = 1 metro é inegociável em VR?

    No headset, o usuário mede a cena com o próprio corpo. Um modelo em milímetros vira uma ponte de 25 km; em centímetros, uma maquete.

    A escala correta faz o usuário sentir a altura do gabarito e o espaço sob o tabuleiro, o que não aparece numa tela.

    Desempenho

    Por que a cena que roda bem no notebook enjoa no headset?

    O headset precisa de 72 a 90 quadros por segundo, desenhando duas vezes (um olho de cada vez). Queda de quadros causa desconforto.

    Use a malha simplificada do curso 12 e junte geometrias do mesmo material. A nuvem densa completa não cabe no orçamento.

    Rig do usuário

    Como colocar o inspetor em pé sobre o apoio P2 ao entrar?

    Em XR a câmera é controlada pelo headset. Para mover o usuário, coloque a câmera dentro de um grupo (rig) e mova o grupo.

    Vistas pré-definidas servem como roteiro de inspeção: o usuário salta entre os pontos que o laudo cita.

    Controles

    Como reagir ao gatilho do controle?

    Cada controle é um objeto 3D com eventos como selectstart e selectend (gatilho) e squeeze (botão lateral).

    Um raio visível dá ao usuário a mesma precisão de um ponteiro laser apontado para o elemento.

    Selecionar elemento

    Como descobrir qual longarina o controle está apontando?

    Monte um raio a partir da posição e orientação do controle e teste a interseção com os objetos da cena.

    Guarde o GlobalId em userData ao carregar o IFC. O mesmo id abre fotos, fissuras e leituras do elemento.

    Painel no espaço 3D

    O painel HTML de dados some quando entro no VR. Por quê?

    Em modo imersivo só a cena WebGL aparece. Desenhe o painel num canvas e use-o como textura de um plano 3D.

    Painel de 0,8 m a cerca de 1,5 m do usuário fica legível. Texto pequeno demais é o problema mais comum em VR.

    Teleporte

    Como andar ao longo de um vão de 25 m sem causar enjoo?

    Teleporte: o usuário aponta para o chão, solta o gatilho e aparece lá. Movimento contínuo causa enjoo em muitas pessoas.

    Limite o teleporte a superfícies navegáveis (tabuleiro, passarelas, terreno) para o usuário não "flutuar" no vão.

    AR em campo

    Como sobrepor o modelo e as fissuras registradas à ponte real?

    Use ARButton com a sessão immersive-ar. O alinhamento com a estrutura real exige pontos de referência conhecidos.

    Na revisita, o inspetor vê no lugar exato onde estava a fissura da campanha anterior e compara ali mesmo.

    Testar sem headset

    Como desenvolver a parte de VR sem colocar o headset a cada mudança?

    Use uma extensão de emulação WebXR no navegador do computador. Ela simula headset e controles.

    O passo 4 não tem substituto: desempenho e conforto só se avaliam no aparelho real.

    Renderização foveada

    Como ganhar desempenho no headset sem simplificar mais o modelo?

    A renderização foveada reduz a resolução nas bordas da lente, onde o olho enxerga menos detalhe.

    É um ganho quase de graça em headsets autônomos. Compare o FPS com e sem antes de decidir o nível.

    Início e fim da sessão

    Como trocar a interface quando o usuário entra e sai do VR?

    O gerenciador XR do renderizador emite eventos de início e fim de sessão.

    Ao sair do VR, devolva o usuário à vista de mesa, com os painéis HTML de volta.

    Régua em VR

    Como medir uma distância no modelo apontando dois pontos com o controle?

    Guarde os dois pontos de interseção do raio, desenhe uma linha entre eles e mostre a distância num painel.

    Medir o gabarito ou o comprimento de uma fissura no modelo é uma das funções mais pedidas por inspetores em VR.
